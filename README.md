## 📖 Sobre o projeto

**Spotimy** é um projeto simples feito em **Java**, com o objetivo de praticar lógica de programação e conceitos da linguagem através de uma temática inspirada no Spotify. Não é um projeto elaborado ou com pretensão de uso real — apenas um exercício rápido para fixar conceitos.

---

## 🛠️ Tecnologias

- Java

---

## ⚙️ Como executar

```bash
# Clone o repositório
git clone https://github.com/kevinhsdev/Spotimy.git

# Entre na pasta do projeto
cd Spotimy

# Compile e execute
javac Main.java
java Main
```
